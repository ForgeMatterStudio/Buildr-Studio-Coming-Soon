## Desenvolvimento Android em qualquer lugar.

Buildr Studio é um ambiente de desenvolvimento Android mobile-first criado para levar fluxos reais de desenvolvimento para celulares e tablets.

Escreva código. Gerencie projetos. Trabalhe com Git. Execute builds. Diagnostique problemas. Visualize seu aplicativo.

Tudo em um único ambiente.

## O que estamos construindo

- Desenvolvimento em Kotlin e Java
- Compreensão de projetos Android e Gradle
- Editor de código integrado
- Diagnósticos em tempo real
- Terminal integrado
- Fluxos de Git e GitHub
- Monitoramento e diagnóstico de builds
- Live View
- Importação e gerenciamento de projetos
- Ferramentas de release e distribuição
- Desenvolvimento e diagnóstico assistidos por IA

## Mobile first. Sem limitar o desenvolvimento ao mobile.

O Buildr Studio está sendo projetado para que um celular possa funcionar como um ambiente real de desenvolvimento Android, e não apenas como complemento de uma IDE de desktop.

Em telas maiores, a experiência será expandida para um workspace mais completo com múltiplos painéis.

## Status de desenvolvimento

O Buildr Studio está atualmente em desenvolvimento privado ativo.

Ainda não existe uma versão disponível para download público.

Um beta fechado e limitado está planejado antes do lançamento público.

## Beta fechado

A primeira fase de testes terá foco em:

- Compatibilidade com dispositivos
- Estabilidade do editor
- Compatibilidade com projetos Android
- Confiabilidade das builds
- Integração com GitHub
- Diagnósticos
- Desempenho
- Fluxos reais de desenvolvimento

Mais informações serão divulgadas quando as inscrições para o beta estiverem disponíveis.
