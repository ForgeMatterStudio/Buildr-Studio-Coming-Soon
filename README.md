## Android development, anywhere.

Buildr Studio is a mobile-first Android development environment designed to bring real development workflows to phones and tablets.

Write code. Manage projects. Work with Git. Run builds. Diagnose problems. Preview your application.

All from one workspace.

## What we're building

- Kotlin and Java development
- Android and Gradle project awareness
- Integrated code editor
- Real-time diagnostics
- Integrated terminal
- Git and GitHub workflows
- Build monitoring and diagnostics
- Live View
- Project import and management
- Release and distribution tooling
- AI-assisted development and diagnostics

## Mobile first. Not mobile limited.

Buildr Studio is being designed so that a phone can be a real Android development environment, not merely a companion to a desktop IDE.

Larger screens will expand the experience into a richer multi-panel workspace.

## Development status

Buildr Studio is currently under active private development.

There is no public download available yet.

A limited closed beta is planned before public release.

## Closed Beta

The first testing phase will focus on:

- Device compatibility
- Editor stability
- Android project compatibility
- Build reliability
- GitHub integration
- Diagnostics
- Performance
- Real-world development workflows

More information will be announced when beta applications become available.
